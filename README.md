# React Accessible Date Picker (Brief C Rebuild)

A professional-grade, accessible calendar dropdown component built with **React**, **TypeScript**, and **Tailwind CSS**. Designed as a high-fidelity rebuild of standard web date picker components.

## Prerequisites & Tech Stack
Ensure you have the following installed before running locally:
- **Node.js**: `v20.11.0` or higher
- **npm**: `v10.2.0` or higher
- **Git**: Latest stable version

## Local Setup Instructions
